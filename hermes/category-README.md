# mattpocock/ — Matt Pocock (AI Hero) engineering skill pack

Generated by `hermes/port.py` in the fork https://github.com/priceflex/skills (branch
`hermes-port`) from upstream `mattpocock/skills`. Do not hand-edit this directory: change
`port.py`, run `./hermes/port.py --install`, and commit both places.

## The main flow, idea to ship

    setup-matt-pocock-skills (once per repo: issue tracker, triage labels, domain docs)
    -> grill-with-docs / grill-me / wait-what / to-questionnaire   (align)
    -> prototype / research                                        (only if a question needs code)
    -> to-spec -> to-tickets   (or `wayfinder` for a fuzzy multi-ticket map)
    -> implement (TDD at agreed seams) or implement-spec (parallel delegate_task children)
    -> mattpocock-code-review (Standards + Spec, two parallel reviewers) -> pr -> retro

Reference skills: tdd, diagnosing-bugs, codebase-design, domain-modeling,
improve-codebase-architecture, writing-for-agents, teach, handoff,
ask-matt (router: "which skill fits this situation?").

## Port transforms (exactly what differs from upstream)

- Skipped, already provided by an existing Hermes skill of the same name:
  - `grilling`: the existing top-level skill is Matt's earlier one-question-at-a-time version.
    Upstream's current one asks a numbered round of questions at once.
  - `wayfinder`: the existing top-level skill is a local-markdown adapted copy.
- Renamed: `code-review` -> `mattpocock-code-review`, because Hermes' own `code-review` is
  an unrelated security checklist. Every reference in the pack is rewritten to match.
- Hermes runtime notes: SKILL.md files that use Claude Code mechanics get a block between
  `<!-- hermes-port:begin -->` and `<!-- hermes-port:end -->`. The block maps the Skill tool to
  `skill_view` and sub-agents to `delegate_task`.

Unchanged and fine as written: `CLAUDE.md` / `AGENTS.md` references (Hermes loads both as
project context), git worktrees (run through `terminal`), and `/skill-name` slash mentions
(Hermes exposes installed skills as slash commands).

## Usage

In a repo, run `setup-matt-pocock-skills` once. Pick the local-markdown tracker for zero
external tooling, or GitHub via `gh`. After that, ask by situation: "grill me on this plan",
"to-spec this", "implement test-first", "review since main".
